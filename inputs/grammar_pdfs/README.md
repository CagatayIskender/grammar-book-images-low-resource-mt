# Grammar Sources

The grammar books used in this study are copyrighted and are **not included** in
this repository. The derived grammar packages actually given to the models
(summaries, tables, cheat sheets and selected page images) are already in
`materials/`, so the saved results and reports can be checked without these PDFs.

You only need the PDFs to rebuild the grammar packages from scratch. Obtain each
source yourself and place it at the path shown, keeping the exact file name.

| Language | Source | Expected path |
| --- | --- | --- |
| Gitksan | Brown, J., Davis, H., Schwan, M. and Sennott, B. (2016). Gitksan. *Journal of the International Phonetic Association* 46(3), 367–378. [doi:10.1017/S0025100315000432](https://doi.org/10.1017/S0025100315000432) | `gitksan/pdf1_brown/gitksan Grammar PDF 1.pdf` |
| Gitksan | Rigsby, B. (n.d.). *Excerpts from the Introduction to Gitksan Grammar*. Scanned introductory excerpt. | `gitksan/pdf2_rigsby/gitksan Grammar PDF 2(1986_Rigsby).pdf` |
| Lezgi | Haspelmath, M. (1993). *A Grammar of Lezgian*. Mouton Grammar Library 9. Berlin: Mouton de Gruyter. ISBN 3-11-013735-6 | `lezgi/grammar/Lezgi_Grammar_PDF.pdf` |
| Natugu | Boerger, B. H. (2022). *A Grammar Sketch of Natqgu [ntu]: An Oceanic Language of Santa Cruz, Solomon Islands*. [langlxmelanesia.com/tilp](https://www.langlxmelanesia.com/tilp) | `natugu/grammar/Boerger_Natqgu grammar sketch_final.pdf` |
| Tsez | Comrie, B. and Polinsky, M. (n.d.). *Tsez*. Author manuscript. [mariapolinsky.com](https://www.mariapolinsky.com/wp-content/uploads/2013/12/Tsez_Final.pdf) | `tsez/grammar/Tsez_Grammar_PDF.pdf` |

Paths are relative to this folder (`inputs/grammar_pdfs/`). Appendix C of the
thesis describes which pages and sections were used for each package.
